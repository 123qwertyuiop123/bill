# 第十一批离线工具实施说明

日期：2026-09-21。

状态：依据用户授权，由开发代理完成 UI 自审后直接开发。

## 范围与去重

- 新增 `coordinate_tool`“地理坐标”：手动进行十进制度与度分秒转换，并计算两点的大圆距离和初始方位。现有 `geometry_calculator` 只覆盖平面矩形、圆形和三角形，交互与计算模型不同，不构成功能重复。
- 颜色格式转换扩展 `color_contrast`，不创建重复工具入口。保留既有 WCAG 对比度和色觉模拟。
- 数据容量换算扩展 `unit_converter`，不创建第二个通用单位换算入口。保留既有长度、重量和温度换算。

注册表预计从 50 个工具增加到 51 个。

## UI 自审

设计图：`offline-tools-batch-11-v1.png`，1:1 画布。

审查结论：通过。三个页面沿用既有浅色背景、白色卡片、细边框、深绿色主按钮、Material 字体图标和顶部返回栏；没有改变主导航、全局信息架构或核心工作流。界面文字为简体中文，主操作清晰，内容可滚动。实现需继续验证 320 像素窄屏、横屏和两倍字体。

设计图中的颜色数值用于表现排版；实现按标准公式计算，`#197A4A` 的 HSL/HSV 色相约为 `150.31°`，以代码结果为准。

## 安全、性能与实现边界

- 坐标全部由用户手动输入；不申请位置权限、不读取 GPS、不联网。纬度限制为 -90 至 90，经度限制为 -180 至 180；对极点、反经线和重合点给出稳定结果或明确提示。距离使用 WGS84 平均地球半径的球面近似，不用于测绘或导航。
- 颜色只接受有界的 HEX、RGB、HSL、HSV 文本，严格校验通道范围与格式；不读取图片、不保存输入。
- 数据容量换算明确区分十进制 KB/MB/GB/TB 与二进制 KiB/MiB/GiB/TiB，限制非有限值和过大输入；不读取文件大小。
- 三项能力均为同步轻量计算，不引入依赖、权限、存储或后台任务。

## 调研来源

- `navibyte/geospatial`，BSD-3-Clause；仅参考坐标与球面计算能力范围。
- `TinyCommunity/tinycolor2`，MIT；仅参考常见颜色格式与转换范围。
- `75lb/byte-size`，MIT；仅参考十进制与二进制容量单位区分。

外部项目只用于功能和交互调研；实现使用项目内 Dart 代码，不复制第三方代码。
