# 第十二批离线工具扩展方案

## 去重结论

- 图片元数据隐私检查与现有图片选择、大小限制、原生后台处理和重新编码流程高度重合，因此扩展 `image_optimizer`，不新增入口。
- 国际化域名转换属于 URL 文本处理，扩展 `url_tool`，不创建单独的域名工具。
- 主题色阶复用现有颜色解析、对比度和复制交互，扩展 `color_contrast`，不新增入口。
- 工具注册总数保持 51，三个稳定 ID 不变。

## UI 自审

- 设计沿用浅色画布、白色卡片、绿色主按钮、细边框和 Material 字体图标，与已确认设计系统一致。
- 三项功能仅增加原工具内页签，没有改变首页、分类、收藏、设置四项导航，也没有改变主要信息架构。
- 操作顺序均为输入或选择、执行、查看结果；错误、空状态和隐私提示靠近对应操作。
- 列表、横向页签与可换行色块适配窄屏、横屏和两倍字体；交互目标保持可触控尺寸。
- 初稿 Punycode 示例经标准校验后已修正为 `xn--h6qv61a4jx.example`，最终设计图使用正确值。

## 功能与安全边界

### 图片隐私检查

- 继续使用 Android 系统文档选择器，只获得单张图片的临时只读能力。
- 保持 20 MB、2400 万像素和 JPEG/PNG/WebP 限制。
- 图片字节留在 Android 原生缓存，检查在单线程执行器中完成。
- MethodChannel 只回传经过长度限制的拍摄时间、设备型号、位置字段布尔值和方向枚举；绝不回传经纬度、URI、文件路径、原始 EXIF 或图片字节。
- 结果不持久化；重新编码的优化输出继续默认移除元数据。

### 国际化域名转换

- 纯 Dart 实现 RFC 3492 Punycode，输入上限 512 个字符、每个 ASCII 标签上限 63 个字符、完整 ASCII 域名上限 253 个字符。
- 拒绝协议、端口、账号、路径、空标签、控制字符、非法 ASCII 标签、溢出和非规范 ACE 标签。
- 不执行 DNS、注册可用性或可信度检查，不打开或请求域名；也不宣称提供完整 IDNA 注册有效性判断。

### 主题色阶

- 只接受严格的 `#RGB` 或 `#RRGGBB`，固定生成 10/30/50/70/90 五档 HSL 明度色阶。
- 前景色建议只在黑白之间按 WCAG 对比度选择；用户仍需在实际页面逐项检查。
- 不读取图片、不保存输入、不联网、不增加依赖或权限。

## 依赖、权限与存储

- 不新增 Dart 或 Android 依赖。
- 不新增 Android 权限，不修改 Manifest。
- 不新增持久化字段，不影响账本 TXT、公共目录同步或已有用户数据。
