# 第四批离线工具 UI 生成提示词

生成模式：使用 `imagegen`，以 `design/offline-tools-batch-3-v1.png` 仅作为视觉风格参考，新建 1:1 正方形设计板。

## 核心要求

- 标题：`ZM 工具箱 · 第四批离线工具`
- 副标题：`设计待确认 · 不增加联网能力`
- 2×2 排列四个 Android 工具详情页。
- 延续白色/浅灰背景、深绿色 `#2F6650`、黑色中文文字、细灰边框、轻圆角、极少阴影。
- 只使用返回、搜索、复制、勾选等 Material 字体图标；不要插画、分类图标、渐变和 3D 效果。
- 除 Markdown、HTTP、MIME、MD5、SHA-1、SHA-256、SHA-512 等标准名称外，全部组件使用中文。

## 四个页面

1. `哈希生成`：展示“文件校验”模式、算法选择、文件选择、进度、摘要、预期摘要、校验一致、计算与复制按钮；底部说明“只读取所选文件，不修改或上传”。
2. `Markdown 预览`：展示 Markdown 输入、本地预览、复制与清空按钮；警示“不执行 HTML、脚本或网络资源”。
3. `HTTP 状态码`：展示搜索、1xx 至 5xx 筛选、404 中文说明和相邻状态；底部说明“离线参考，不会发送网络请求”。
4. `MIME 类型`：展示按扩展名/按 MIME 切换、`.json` 查询结果和复制按钮；底部说明“仅按内置表查询，不读取文件内容”。

不要显示底部导航，不裁切手机，不生成乱码或重复标签。
