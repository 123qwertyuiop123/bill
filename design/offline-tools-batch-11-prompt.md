# 第十一批离线工具 UI 生成提示词

使用内置 imagegen，以 `offline-tools-batch-10-v1.png` 为风格参考，在 1:1 画布中并排展示“地理坐标”“颜色与对比度—格式转换”“单位换算—数据容量”三个中文 Android 页面。

- 延续浅薄荷灰背景、白色卡片、细灰绿色边框、深绿色主按钮和 Material 字体图标。
- 地理坐标支持“坐标转换 / 距离方位”，仅手动输入坐标，不读取设备位置。
- 颜色页面支持 HEX、RGB、HSL、HSV 格式转换，结果可复制。
- 单位换算扩展十进制与二进制数据容量单位，并明确 KB 与 KiB 的差异。
- 页面内容可滚动，每页只有一个主操作；避免渐变、重阴影、插画和额外导航。
