调研日期：2026-09-13。

状态：用户已确认设计并要求开始开发；四个工具已实现并单次注册。原账本、TXT 格式与 Android 公共目录同步行为不变。

## GitHub 调研来源

- [贴片电阻计算器](https://github.com/Frenzarectah/Js-SMD-Resistence-Calculator)：三位、四位及 EIA-96 编码；本批仅采用三位、四位数字编码范围。

仅用于功能发现与交互参考，不直接复制代码、素材、设计或依赖。若引用第三方实现，另行检查实际许可证。

## 建议范围与重复检查

已逐项对照 AGENTS 清单与注册表的 45 个工具；四个候选 ID 均未注册。比较的是实际功能而非标题。

| 稳定 ID | 名称 | 第一版范围 | 最接近的已有工具 | 不重复的原因 |
|---|---|---|---|---|
| `resistor_decoder` | 电阻解码 | 4/5 色环阻值、误差及范围；三位/四位数字贴片编码 | 欧姆定律、颜色与对比度 | 输入为元件标识；不求解电气量关系、不检查 WCAG |
| `quadratic_solver` | 二次方程 | ax²+bx+c=0 的实根/复根；a=0 退化处理 | 计算器 | 输入为系数，输出根与判别式，不执行通用表达式 |
| `geometry_calculator` | 几何计算 | 矩形、圆形、三角形面积与周长；三角形使用三边 | 宽高比计算、单位换算 | 计算形状量，不约分比例或换算单位 |
| `matrix_calculator` | 矩阵计算 | 2×2/3×3 的行列式、转置、逆矩阵 | 计算器、统计计算 | 二维结构与线性代数工作流，不做标量或一维统计 |

在任何单一已有工具中，均不存在半数以上的候选主要工作流。四者统一用现有“计算”分类，不添加主导航。

## 排除与扩展决定

- 分数四则暂不新增，先评估扩展计算器的精确分数模式。
- 单位换算、欧姆定律、均值/标准差和罗马数字已覆盖，不新增同类入口。
- NATO/Morse 等通用文本转换优先扩展 `text_tools`。
- EIA-96、六环温度系数、矩阵乘法、更高阶矩阵、三维几何与函数绘图不在本次范围，扩展前另行评审。

## UI 约定

1:1 画布，2×2 展示四个手机页面；深绿色按钮、白卡、细边框、浅色背景与字体图标。仅顶部返回栏，无底部主导航。电阻颜色小色块是输入内容，不是种类图标，必须同时显示中文名称。

- 电阻解码：色环/贴片分段、环数与颜色选择、标称阻值/误差/范围。数字贴片不推断误差。
- 二次方程：三个系数、根类型、根、判别式。
- 几何计算：形状、必要长度、面积与周长；用户统一长度单位，结果注明单位/单位²。
- 矩阵计算：阶数、输入网格、操作、结构化结果；奇异或近奇异输入不输出逆矩阵。

## 安全与性能边界

全部离线，无新权限、持久化或网络；不使用 eval、脚本、CAS 或任意表达式执行。复制只由主动点击触发。

- 电阻：合法颜色校验；ASCII 数字贴片仅 3/4 位；注明“按标识解码，不替代实测”，不指导高压接线。
- 方程：每项最多 32 字符、有限值绝对值 ≤1e100；缩放系数、稳定根公式；处理零系数、重复根、复根与溢出，结果注明近似。
- 几何：长度限定 1e-9–1e9；拒绝非法三角形，使用稳定海伦公式。
- 矩阵：最多 9 个元素；每项最多 32 字符、有限值绝对值 ≤1e12；主元策略、相对容差和近奇异检查，注明数值近似。
- 页面可滚动；测试 320 宽屏、横屏和 2 倍字体；大字体允许纵向布局，无复杂动画和高频实时重算。

界限必须落实到实现、中文提示和测试。

## 确认后的开发

电阻解码 → 二次方程 → 几何计算 → 矩阵计算，逐个实现并测试。各自在 `lib/tools/<稳定 ID>/` 目录，单次注册；同步 AGENTS、README 与开发规范。最后按规范依次格式检查、静态分析、全量测试；涉及依赖或 Android 配置才追加正式构建。

## 实施与检查结果

2026-09-13：四个独立模块均已完成，工具总数为 49；每个模块拆分页面与纯计算逻辑并提供测试。输入、模式或参数改变即清除旧结果，复制仅响应主动点击；无新增依赖、权限、持久化或网络请求。

- 电阻支持位置合法性校验与数字贴片误差未知提示。
- 方程采用缩放与稳定根公式；非零判别式乘积下溢时显式拒绝，不误报重根。
- 几何采用三边合法性校验与稳定海伦公式。
- 矩阵采用归一化、部分选主元与相对阈值；行列式独立消元，归一化精度丢失或结果不可表示时显式拒绝。
- 320×640、640×320 和两倍字体布局/结果展示测试通过；矩阵 3 阶输入可纵向排列。
- 按规范顺序验证：166 个 Dart 文件格式检查无变更；静态分析无问题；全量 205 项测试通过；`git diff --check` 通过。

本次未修改 Android、依赖、权限、平台通道或发布功能，因此未追加正式 APK 构建；本记录不代表真机验收或正式包验证。
