## UI 设计

设计图：`offline-tools-batch-3-v1.png`，1:1 总览画布、四个工具详情页。

- 保持现有深绿按钮、白色卡片、细边框和 Material 字体图标；没有装饰性种类图标。
- 普通标签、错误提示、弹窗均为简体中文。IPv4、Luhn、Unix 等标准名称保留。
- 四个详情页使用统一返回栏，不添加底部主导航；首页、分类、收藏、设置不变。
- 结果出现前展示简短操作提示；输入变更后清除或明确标记旧结果，避免误复制。
- 输入错误在字段附近显示；复制成功提示“已复制”，复制失败显示中文反馈。
- 空结果不允许复制，不自动读取剪贴板，不保存或上传输入。
- 图中为正常结果态；实际页面用滚动布局适配窄屏、大字体及键盘，不固定图中的高度。

### 占位文本

中文示例 / 拉丁占位文切换，段落数量 1–20、每段句数 1–10，默认 3 段、每段 2 句。显式点击“生成文本”，输出最多 20,000 字符。中文采用项目自编句库，不提供在线 AI 生成。拉丁模式只切换结果素材，界面仍使用中文。无效数量不静默截断，提示“段落数量请输入 1–20 的整数”等。

### IPv4 子网计算

仅接受四段十进制 IPv4 和 0–32 的前缀，限制输入长度 64 个字符；拒绝无效、缺失及歧义地址。只做位运算，不发起请求、扫描或主机探测，不枚举整个网段。普通子网按网络和广播地址排除计算可用范围；/31 按点对点语义显示两个地址并标明无传统广播；/32 显示单主机地址，不机械减 2。开发时补齐 /0、/31、/32 测试。

### 权限计算

第一版仅支持三位 000–777 和九个普通权限位。八进制输入和勾选双向同步，输出九字符权限表示；特殊权限位暂不提供。错误输入提示“三位权限只能使用 0–7”。只输出结果，不生成带用户路径的命令、不执行 chmod、不改变 Android 权限。图中 755 对应 rwxr-xr-x。

### Luhn 校验

“校验号码”模式输入含校验位的完整序列，展示通过 / 未通过；“生成校验位”模式输入不含校验位的数字，主按钮改为“生成校验位”，展示校验数字和拼接后的完整序列。仅接受 ASCII 数字，保留前导零；校验长度 2–128，生成模式 1–127，拒绝其他字符。图中 12344 符合规则，1234 的校验位为 4。所有结果态都保留“不代表号码真实、存在或可用”的说明。结果仅在内存中，不请求敏感权限、不保存或输出号码日志。

## 确认后的执行顺序

1. 用户确认本批工具范围与设计后，重新核对规范、注册表及工作区改动。
2. 每个工具一个独立 `lib/tools/<tool_name>/` 目录，页面与计算逻辑拆分，补充中文边界注释。
3. 每完成一个工具就检查正常输入、空输入、非法输入、极值和关键交互。
4. 注册一次，并同步更新 AGENTS.md 工具清单和 README；不要把本提案当作已实现清单。
5. 按规范依次执行格式检查、静态分析、完整测试和必要的正式构建。
