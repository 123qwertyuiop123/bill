# 第十二批离线工具扩展 UI 提示词

## 生成模式

- 工具：内置 ImageGen
- 类型：UI mockup
- 比例：1:1
- 参考：`design/offline-tools-batch-11-v1.png`

## 主提示词

生成一张 1:1 的中文 Flutter 工具箱 UI 设计图，延续现有朴素、本地优先的设计系统：浅色背景、白色卡片、绿色主色、细边框、Material 字体图标、无渐变和无毛玻璃。画面并排展示三个手机详情页：

1. “图片优化”的“隐私检查”页签：通过系统选择器选择一张 JPEG/PNG/WebP 图片，显示文件名、尺寸与大小；点击“检查元数据”后只展示拍摄时间、设备型号、GPS 位置字段是否存在和图片方向。明确说明元数据仅在本机读取、不保存、不上传，优化输出仍会移除元数据。
2. “URL 编解码”的“国际域名”页签：提供 Unicode → ASCII / ASCII → Unicode 方向、域名输入、转换按钮、只读结果与复制图标。示例输入“工具箱.example”，结果必须准确显示 `xn--h6qv61a4jx.example`。说明 Punycode 转换不代表域名可信，不打开网址。
3. “颜色与对比度”的“主题色阶”页签：输入 HEX 种子颜色 `#197A4A`，生成 10/30/50/70/90 五档色阶，并显示建议前景色与复制图标。说明色阶离线生成，发布前仍需检查文字对比度。

全部用户文案使用简体中文；URL、Punycode、ASCII、GPS、HEX 等标准缩写可保留。界面兼顾窄屏、大字体和触控尺寸，不改变首页导航或工具入口。

## 校正提示词

保留原图布局、三个手机、配色、字体、图标和所有其他文字，仅把中间手机“转换结果”中的错误示例修正为精确字符串 `xn--h6qv61a4jx.example`。
