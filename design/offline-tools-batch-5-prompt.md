# 第五批离线工具 UI 生成提示词

生成模式：使用内置 `imagegen`，以 `design/offline-tools-batch-4-v1.png` 仅作为视觉风格参考，新建 1:1 正方形设计板。

## 核心要求

- 标题：`ZM 工具箱 · 第五批离线工具`
- 副标题：`设计待确认 · 2 个新增 + 2 个扩展`
- 2×2 排列四个 Android 工具详情页。
- 延续白色/浅灰背景、深绿色 `#2F6650`、黑色中文文字、细灰边框、轻圆角、极少阴影。
- 只使用 Material 字体图标；不要分类插画、装饰图标、渐变或 3D 效果。
- 除 HMAC、HTML、JPEG、PNG、WebP、SHA-256、SHA-512 等标准名称外，全部组件使用中文。

## 四个页面

1. `图片优化`：选择图片、目标宽高、保持比例、禁止放大、质量、输出格式、元数据开关、优化结果与保存按钮；明确 20 MB / 2400 万像素上限和不上传图片。
2. `宽高比计算`：原始宽高、约分比例、小数比例、方向、等比换算、常见预设与复制结果；不读取图片。
3. `哈希生成`：在现有工具中增加 HMAC 模式，使用 SHA-256 / SHA-512、隐藏共享密钥、消息内容、结果与安全说明。
4. `文本工具`：在现有工具中增加 HTML 实体编码/解码，展示输入、结果、复制和清空；明确只转换字符，不渲染或执行 HTML。

不要显示底部导航，不裁切手机，不生成乱码、重复标签或英文导航。
