# 第八批 UI 图最终提示词

模式：内置 image_gen；用途：ui-mockup；状态：待确认。

Use case: ui-mockup
创建 1:1 正方形高清中文 Android 工具箱 UI 评审图，四个完整手机页面以 2×2 网格等距排列。延续 ZM 工具箱已确认风格：朴素清晰、低对比浅灰绿色背景、白色卡片、深绿色 #2f6650 主按钮、细浅灰边框、12–16 圆角、几乎无阴影。只用 Material 字体图标，不用照片、插画、分类图标、渐变、玻璃效果。每个页面顶部为返回箭头和标题，不加收藏星标、不显示底部导航。中文文字准确，数字和公式清晰，四台手机同尺寸，完整显示，不裁切。所有界面用简体中文，标准字母和单位除外。

左上：标题“电阻解码”。顶部分段“色环解码”选中、“贴片编码”未选中。卡片中下拉“色环数量：4 环”，四个紧凑纵向选择行：“第 1 环 棕色”“第 2 环 黑色”“倍率 红色”“误差 金色”，每个颜色名称前仅放功能必要的小色块，不画电阻插图。主按钮“开始解码”。结果卡“标称阻值 1 kΩ”“误差 ±5%”“范围 950–1050 Ω”。底部提示“按标识解码，不替代实测”。

右上：标题“二次方程”。顶部公式“ax² + bx + c = 0”。白卡三个输入“系数 a 1”“系数 b -3”“系数 c 2”。主按钮“求解方程”。结果卡“两个不同实根”“x₁ = 1”“x₂ = 2”“判别式 Δ = 1”。下方提示“仅支持固定形式，不执行表达式”。

左下：标题“几何计算”。顶部形状分段“矩形”选中、“圆形”“三角形”。白卡两个输入“长度 12”“宽度 8”，辅助文字“所有长度使用相同单位”。主按钮“开始计算”。结果区两列卡片“面积 96 单位²”“周长 40 单位”。公式卡“面积 = 长 × 宽”“周长 = 2 × (长 + 宽)”。底部“只做数值计算，不测量图片”。

右下：标题“矩阵计算”。选择“矩阵阶数：2 × 2”，白卡用清晰 2×2 网格输入数字第一行“1  2”，第二行“3  4”，细括号包围网格。下拉“操作：行列式”，辅助“还支持转置和逆矩阵”。主按钮“开始计算”。结果卡“行列式 det(A)”“-2”。底部提示“支持 2 × 2 和 3 × 3；结果为数值近似”。

所有手机页面保持触控按钮足够大、信息层级明确、输入框可读。画布均匀留白，不添加主导航、品牌口号或额外工具。
