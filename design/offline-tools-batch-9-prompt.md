# 第九批 UI 图生成说明

生成方式：内置图像生成工具；参考 `offline-tools-batch-8-v1.png` 的现有视觉体系。

目标：1:1 设计板，展示“颜色与对比度”“贷款计算”“二维码与条码”三个手机详情页，以及中文、窄屏、大字体、离线四项审查标记。

约束：浅色背景、白卡、细边框、深绿色按钮、Material 字体图标、简体中文、无底部主导航、无插画、无渐变、无复杂阴影。颜色页包含对比度/色觉模拟；贷款页包含本金、固定年利率、期数、摘要和前六期明细；编码页包含二维码/一维条码、Code 128 和条码预览。

初次输出的条码页面标题有文字错误，已进行一次只改标题的定向编辑；最终图标题为“二维码与条码”。UI 自审通过后进入开发。
